# Delivery Companion

Quero um sistema que não custe muitos créditos para gerar que funcione para motoboys relacionar uma entrega via offline com a localização ativa e contar os km rodados e ao iniciar a corrida e função para futuramente criar um login e acessar a administrativo para ver a localização desse motoboy Também verifique a função lá que com todos os km tendo a disponibilidade de adicionar um local fixo da operação para o roteamento e poder fazer automático talvez sem selecionar
